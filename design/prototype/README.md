# EV Monitor — เว็บบริหารกองยานรถยนต์ไฟฟ้า

ธีมอ้างอิงจากหน้าโซลูชัน EV ของ Webfleet: navy เข้ม + พื้นขาว, ปุ่มหลักสีแดง, การ์ดเรียบเส้นบาง, ฟอนต์ IBM Plex Sans Thai

## หน้าเว็บ
| ไฟล์ | หน้า |
|---|---|
| index.html | หน้าแรก (Landing) — Hero, ฟีเจอร์ 6 ด้าน, บล็อกรายละเอียด, FAQ, CTA |
| login.html | เข้าสู่ระบบ |
| dashboard.html | แดชบอร์ดภาพรวม (พัฒนาต่อจากหน้าเริ่มต้นเดิม) |
| map.html | แผนที่สด + สถานีชาร์จ + ชั้นข้อมูล |
| alerts.html | การแจ้งเตือน (กรอง/รับทราบได้) |
| vehicles.html | รถทั้งหมด (ค้นหา กรอง เรียง ส่งออก CSV) |
| vehicle.html?id=EV-001 | รายละเอียดรถรายคัน |
| battery.html | สถานะแบตเตอรี่ SoC / SoH |
| charging.html | การชาร์จ เซสชัน สถานี ค่าใช้จ่าย |
| drivers.html | พนักงานขับรถ คะแนน Eco-Driving |
| reports.html | รายงาน: พลังงาน, CO₂, ความพร้อมเปลี่ยนเป็น EV, การใช้งาน |
| settings.html | ตั้งค่าองค์กร เกณฑ์แจ้งเตือน ผู้ใช้ การเชื่อมต่อ |

## ไฟล์ร่วม
- `style.css` — ระบบดีไซน์ทั้งหมด (สี ตัวอักษร คอมโพเนนต์ responsive)
- `app.js` — Sidebar/Topbar, ไอคอน SVG, helper แผนที่และกราฟ
- `data.js` — ข้อมูลตัวอย่าง (เปลี่ยนเป็น API จริงได้ที่ไฟล์นี้)

## การใช้งาน
ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์, แผนที่ (Leaflet + CARTO) และกราฟ (Chart.js)
